# Calculator Tool

Calculation Tool is a mobile application that allows you to make calculations such as hydraulic efficiency, power calculation, and pipe friction loss in a matter of seconds.

## Features

- Hydraulic efficiency calculation
- Power calculation
- Pipe friction loss calculation

## Installation

1. Clone the project:
- git clone https://github.com/mustafawp/CalculatorTool.git

2. Navigate to the project directory:
- cd CalculatorTool


3. Install the required dependencies:
- flutter pub get


4. Run the application:
- flutter run
